# 立体视界

在浏览器里把一张照片做成两种可交互的空间预览：

1. **裸眼 3D**：用景深把近处的人和物体轻轻顶出画面。指针移动或自动摆动时，近处位移更大，看起来像从屏幕里浮出来。
2. **空间场景**：站在照片前面，拖动即可 360° 环视，也可以改成环绕这张立体照片。

不需要账号，也不需要 API key。照片不会上传到服务器。景深模型在本机运行；只有第一次使用时需要联网下载模型。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开终端里提示的地址，默认是 [http://127.0.0.1:43127](http://127.0.0.1:43127)。

生产构建：

```bash
npm run build
npm run preview
```

建议使用较新的桌面版 Chrome、Edge、Firefox 或 Safari。页面需要 WebGL 和 WebAssembly。

## 怎么用

- 把 JPG、PNG 或 WebP 拖进页面，或点击选择文件。单张不超过 20 MB。
- 也可以先点「人像示例」或「风景示例」。
- 用顶部的「裸眼 3D」「空间场景」切换两种预览。两套预览共用同一张景深。
- 「反转远近」在景深把前后看反时使用。亮处默认表示更近。
- 裸眼 3D 可以开关「自动摆动」和「跟随指针」，并考节景深强度。
- 空间场景默认是「环视」：拖动左右看一圈，滚轮缩放，方向键也能转。改成「环绕」后，可以绕着照片本身转动。

第一次分析会下载景深模型，大约 27 MB，之后留在浏览器缓存里。下载或运行失败时，页面会改用快速近似景深，并允许再试一次。

## 裸眼 3D 是怎么做的

这里的「裸眼 3D」是普通显示器上的**视差浮雕**，不是柱镜光栅屏那种硬件立体。

1. 用 [Depth Anything V2 Small](https://huggingface.co/onnx-community/depth-anything-v2-small)（`q4` 量化，Apache-2.0）估计每个像素的相对远近。模型通过 [Transformers.js](https://huggingface.co/docs/transformers.js) 在 Web Worker 里用 WASM 运行。
2. 把原图贴在一块细密网格上，近处的顶点向镜头凸起，画面四边钉住，避免整张照片被撕开。
3. 网格后面放一层模糊的原图。镜头轻轻平移或自动摆动时，清晰的前景相对背景移动，深度就显出来了。
4. 正对着看时浮雕几乎是平的。所以默认开着摆动。关掉摆动和指针跟随之后，需要再打开其中一项才能看出前后。

原图的颜色和细节没有被重绘，五官和背景仍是上传的像素。

## 空间场景是怎么做的

1. 同一张景深把照片铺到一段朝向观众的弧形网格上，近处沿径向向观众凸起。
2. 相机放在弧形里面。环视只改水平角和俯仰，可以转满 360°。
3. 照片盖住的是前方这一段。左右和背后是一张环境球：颜色取自原图**边缘**，并做了强烈模糊。这样背后不会出现一个被涂开的人影，也不会假装那里真的有一间房间。
4. 照片边缘会淡进这层环境色，避免一条硬切边。
5. 「环绕」使用轨道控制，绕着照片转动，方便从侧面看凸起。

正面的人和背景仍然是原图像素，只是网格按远近起伏。

## 已知限制

- 单目景深是估计，不是激光扫描。头发丝、眼镜、透明物体、细遮挡和很平的背景容易粘连或漏。
- 角度过大时，网格会被拉开，边缘出现拉伸。强度滑杆就是用来收着这一点的。
- 快速近似景深只根据画面中心、下方和局部对比做一个大概的前后，不能替代模型。失败提示出现时，检查网络后再点「重新分析」。
- 空间场景的侧面和背后**不是**生成式补全。转过去看到的是原图边缘的色彩氛围。
- 环绕到照片背面时，会看到同一张图的背面，而不是相机背后的真实空间。
- 预览图最长边大约 1600 像素，送给模型的图最长边大约 768 像素。更大的原图会先缩小。
- 模型在 WASM 上是单线程，一张图通常要几秒。页面在分析完成前会挡住预览。

## 可选的云端增强

基本演示不考用任何云端接口。如果希望背后也是可观看的场景，而不是色彩氛围，可以另行接入图像外扩或单图转全景的服务。建议只替换 `src/lib/images.ts` 里 `buildAtmosphere` 生成的环境贴图，正面的原图网格可以保持不变。那一步需要你自己的接口和密钥，本仓库不内置。

## 项目结构

```text
src/lib/depthModel.ts      加载 Depth Anything V2 Small
src/workers/depth.worker.ts  在 Worker 里跑模型，避免卡住界面
src/lib/depth.ts           景深归一化、平滑，以及失败时的近似景深
src/lib/images.ts          读图、缩放，以及环境球 / 地面的色彩
src/lib/displace.ts        把景深写进 Three.js 网格
src/components/NakedEyeView.tsx
src/components/SpatialView.tsx
public/samples/            两张示例照片
```
